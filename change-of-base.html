Change of Base Formula Unlocked

When evaluating a logarithm with an unfamiliar base $b$, you can rewrite it as a quotient of logarithms using any new standard base $k$ (typically base 10 or base $e$):

logb(x) = logk(x) / logk(b)

For example, to evaluate log4(16), convert to base 2:
log2(16) / log2(4) = 4 / 2 = 2.
